3-minute demo script

Use two windows side by side: laptop = organiser, phone (or a second window) = student.

  1. Laptop: log in as exec@uniloop.demo → sidebar Organiser. Leave it open; the dashboard refreshes every 3 seconds.
  2. Phone: open the same link → log in as student@uniloop.demo → on Discover use Where / When / What → open an event → RSVP.
  3. Laptop: within 3 seconds the new RSVP appears at the top of Recent RSVPs, flashes orange, and the RSVP counter goes up by one.
  4. Phone: My stuff → Show ticket → a QR code plus a short ticket code.
  5. Laptop: Scan tickets → paste the ticket code (or use the camera on a phone) → the attendee is checked in. Scan again and it says “already checked in”.
  6. Optional: ＋ New event publishes an event that shows up on Discover immediately.

What each role can do

Student

  • Search with a staged filter: Where (campus) · When (window or a specific day) · What (category)
  • Save events; saved items sync across the app
  • RSVP with capacity, one-ticket-per-person and campus-only rules enforced by the server
  • Join a club (mock payment) → member pricing applies automatically
  • Ticket with QR code and check-in status
  • Every event keeps its official registration link (opens the original club page)

Organiser

  • Live KPIs: RSVPs, fill rate, page views, revenue
  • Cumulative RSVP curve with capacity line and projection
  • Recent RSVPs list with ticket codes and check-in state
  • Members list
  • Ticket scanning (paste code or camera)
  • Create and publish events

If something does not work

  • The public link does not open: use http://localhost:3400 on the demo machine. The public address is a tunnel that is re-pointed automatically, but it can take a minute after a restart.
  • Camera scanning does nothing: browsers only allow camera access on localhost or HTTPS. Paste the ticket code instead.
  • Nothing shows on the dashboard: make sure you are logged in as the organiser account and that you are on the Organiser page; demo data is seeded for that club.
  • Want a clean start: delete .sym-data/uniloop-db.json and restart with node server.js.
