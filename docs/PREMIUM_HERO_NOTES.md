# “高级感首页”学习笔记（用于 Hero 改版）

> 参考对象：Luma（浅色、克制）、Partiful（深色大图 + 白字）、DICE（黑底海报）、Airbnb（搜索胶囊悬浮）
> 结论：高级感 ≠ 加动效，而是 **减少元素 + 提高对比 + 慢节奏**。

## 1. 结构：三层就够

```
① 全幅图片（深色处理）
② 一层渐变遮罩（上深下浅，底部融进纸底色）
③ 文字 + 一个搜索胶囊
```

Partiful / DICE 都是这个结构：**图片占满上半屏，文字压在图片上，交互只有一个入口**。

## 2. 文字：越少越贵

| 做法 | 说明 |
|---|---|
| 一个 kicker（10–11px，大写，字距 .14em） | 例：`TONIGHT ON CAMPUS`，代替日期 |
| 一个衬线大标题（32–36px，两行内） | 例：`Find your kind / of evening.` |
| 一行元信息（12–12.5px，60–80% 白） | 社团 · 时间 · 地点 |
| **不放**：日期、天气、版本号、说明文字 | 用户打开手机就知道今天几号 |

## 3. 遮罩：决定“贵不贵”的关键

```css
linear-gradient(180deg,
  rgba(10,18,14,.72) 0%,     /* 顶部压暗，保证白字可读 */
  rgba(10,18,14,.42) 38%,
  rgba(10,18,14,.18) 58%,
  rgba(244,241,231,.06) 76%,
  var(--paper) 100%)         /* 底部融进页面底色，没有“硬边” */
```
> 硬边（图片一条直线切到白底）是廉价感的主要来源。

## 4. 动效：慢 + 少

| 做法 | 参数 |
|---|---|
| 图片缓慢切换 | 4 张图，每张 8 秒，淡入淡出 32 秒一轮 |
| 图片轻微推近（Ken Burns） | `scale(1.04) → scale(1.10)`，跟整个周期同步 |
| 文字切换 | 只换元信息（社团/时间/地点），标题不动（避免跳动） |
| 入场动画 | 区块 `translateY(10px) + opacity`，500ms，不做视差 |
| **不要** | 持续自动滚动的横向列表（会晕）、无限循环 marquee、弹跳 |

`prefers-reduced-motion` 时：只显示第一张图，关闭所有动画。

## 5. 搜索：胶囊悬浮在“图片与页面交界”

- 搜索胶囊上移 `-30px`，压在 hero 底部 → 视觉上“浮起来”
- 阴影要柔：`0 18px 40px -22px rgba(20,32,27,.45)`
- 三段式（Where / When / What）而不是一个大输入框 → 点击即进入分步面板
- 筛选只留 **4 个“当前值”按钮**，一行放得下（flex:1，不需要横滑）

## 6. 配色：三种就够

| 角色 | 色值 | 用在哪 |
|---|---|---|
| 深色（图片上的底） | `#0E1A15` | hero 背景 / 遮罩 |
| 纸色（页面底） | `#F4F1E7` | 页面背景、卡片外的区域 |
| 强调色 | `#D8583A`（珊瑚） | 唯一的主按钮/余位告警 |
| 辅助绿 | `#1F4A3B` | 次级按钮、图标、选中态 |

再加一层 **3.5% 颗粒噪点**（SVG feTurbulence）→ 纸感，消除“纯色块”的廉价感。

## 7. 我们踩过的坑（这次改掉的）

| 坑 | 改法 |
|---|---|
| 顶部显示日期 | 删除；日期在搜索的 When 里 |
| Try 推荐词 + 两排 chip + 4 个筛选叠在一起 | 推荐词移进搜索面板；筛选压成一行 4 个 |
| 横向列表自动滚动 | 改为手动滑动 + `scroll-snap`，露出半张卡提示可滑 |
| 分步面板用 emoji | 全部换 inline SVG 线性图标 |
| 背景纯色 | 纸色 + 径向渐变 + 颗粒 |
| 选择时间只有"今天/周末" | 增加 21 天日期条（每天显示活动数） |
